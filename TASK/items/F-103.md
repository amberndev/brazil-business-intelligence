### 2. ORDER BY score sem filtro → timeout 30s (correção: 2026-09-06)
- **Root cause**: ORDER BY b.score DESC com WHERE TRUE (nenhum filtro de busca textual) em 72M linhas forçava seq-scan + sort externo, excedendo o command_timeout=30 do pool asyncpg.
- **Correção**: ORDER BY {('b.score DESC' if q else 'b.cnpj')} — usa .score DESC **apenas** quando há query de texto (q); sem q, usa .cnpj (PK btree, busca indexada instantânea com LIMIT/OFFSET).

### 3. Catch-all 500 → JSON envelope
- **main.py**: registrado @app.exception_handler(Exception) que retorna {"error": {"code": "internal_error", "message": "Internal server error.", "status": 500}} em vez do texto puro "Internal Server Error" do Starlette.
