# F-105 — 500 responses return plain-text "Internal Server Error", not the contract error envelope

## F-105 | categoria: funcional | severidade: média | status: aberto
- Tela: search1_hdr.txt / search1_body.json (HTTPS curl)
- Passos: 1) GET https://brazil.ambern.dev/api/v1/search?state=SP with a valid FREE key
- Esperado: CONTRACT §A requires EVERY non-2xx to return `{"error":{"code","message","status"}}`; a 500 must be `{"error":{"code":"internal_error",...}}`.
- Observado: The 500 responses return raw `Internal Server Error` (21 bytes, `Content-Type: text/plain`, `Server: uvicorn`) — the default unhandled-exception page, NOT the JSON error envelope. Confirms the search failure ([[F-103]]) is an UNHANDLED exception (query timeout escapes the app's error handler). Frontend `apiFetch` tries `res.json()` on this body and falls back to `unknown_error`.
- Impact: contract violation for all 500s; clients cannot parse the error; also masks the real cause. A DB timeout should be caught and returned as the enveloped `internal_error` (500).
